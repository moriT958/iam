## サンプルスライド

reveal.js + Astro のデモ

---

## 2 枚目

- Markdown でそのまま書ける
- `---` で新しいスライド
- `--` で縦方向のスライド

---

## コードハイライトも対応

```ts
function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

---

## 発表機能

- `F` : フルスクリーン
- `Esc` : オーバービュー
- `?print-pdf` : PDF エクスポート用レイアウト
